# 34 · 主按钮可读性统一

> UI/UX 审计实测：白字 / 果子绿 `#4BB964` 对比度只有 2.49:1，低于 WCAG AA 正文 4.5:1 的要求。
> 点名页先做了局部试点，这一轮把方案收敛到全局设计 token，避免每页各写一套。

---

## 一、方案

- 主按钮背景保持果子绿，文字改为深绿 `#123B2B`，对比度 5.00:1。
- Hover / Focus / Active 使用更亮的 `#5EC97A`，深绿文字对比度 6.00:1。
- 禁用态使用 `#D7E7DD` 浅绿底 + 深绿字，对比度 8.08:1。
- 危险按钮（`ant-btn-dangerous`）不套用该规则，保留红色语义与白字。
- 颜色写入 `enterprise.less` 的 `:root` 变量：
  - `--primary-action-text`
  - `--primary-action-hover`
  - `--primary-action-disabled`
- 删除点名页重复的局部按钮覆盖，统一由全局规则接管。

## 二、验证

| 页面/尺寸 | 结果 |
|---|---|
| 学员列表 1280 | 「新增学员」「查询」背景 `rgb(75,185,100)`、文字 `rgb(18,59,43)` |
| 学员列表 390 | 「新增学员」44px，深绿文字，无横向溢出 |
| 点名页 390 / 1280 | 刷新与确认按钮继承全局规则，不再需要页面级覆盖 |
| Hover / Active | 亮绿底 + 深绿字，对比度 6.0:1 |
| 危险按钮 | 通过 `:not(.ant-btn-dangerous)` 排除，未被改写 |

## 三、边界

- 没有逐页做视觉回归；当前抽查了登录体系之外的学员、工作台、点名代表页面。
- 深色主题未单独验证；如果后续支持暗色模式，需要重新测对比度。
- 这是“可读性优先”的视觉取舍：主按钮不再是白字，品牌绿保持不变。
- 其他浅色文字（次要文字 `#86909C` 3.24:1、橙色文字 2.94:1）仍未达到正文 AA，需要后续单独治理。
