# 16 · 排课助手、试听自动化与一键初始化

> 本轮补齐三件「让日常操作更省事」的事：排课不再靠人脑避让冲突、试听结束不再靠顾问记着改状态、
> 新环境不再靠手工按顺序导 SQL。

## 一、排课助手：推荐可排课时段

### 解决什么

手动排课时最费时间的是「撞车」：同一班级、同一老师、同一教室在同一时段只能有一节课。
以前的做法是打开周视图一行行看，排完提交被冲突拦住再重来。

现在在「手动排课」弹窗里直接给出未来 7 天的推荐时段，点一下就把日期、开始/结束时间填好。

### 算法

接口：`GET /course/schedule/suggest`

| 参数 | 说明 |
|---|---|
| `classId` | 班级（可选，填了才能读到班级固定课表） |
| `teacherId` | 教师（可选，参与占用判断） |
| `classroom` | 教室（可选，参与占用判断） |
| `startDate` / `endDate` | 推荐区间，默认今天起 7 天，最长 14 天 |
| `durationMinutes` | 单节时长，默认 90 分钟（30–240） |
| `limit` | 返回条数，默认 8 |

计算过程：

1. 一次性查出区间内所有 `NORMAL` 状态的课节；
2. 从班级的 `weekTemplateJson` 解析固定课表（星期 + 起止时间）；
3. 以 30 分钟为步长枚举 09:00–21:00 的候选开始时间；
4. **冲突过滤**：与已有课节的班级、教师、教室任一重叠即跳过；
5. **打分排序**：

| 条件 | 分值 |
|---|---|
| 命中班级固定课表时段 | +40（理由：与班级固定课表一致） |
| 当天有固定课表但候选在其外 | +12（理由：避开了固定课表时段） |
| 当天没有固定课表 | +20（理由：该时段全部空闲） |
| 上午（12:00 前） / 下午 / 晚上 | +12 / +8 / +5 |
| 距离起始日期越近 | +max(0, 7 − 天数) |

6. **去重叠**：按分数从高到低选取，同一天里已被更高分时段覆盖的候选不再返回，
   保证用户在弹窗里看到的每一条都是「选了它不会和另一条冲突」的。

### 前端交互

- 打开「手动排课」立即按当前筛选的班级出推荐；
- 切换班级、选教师、填教室失焦都会刷新推荐；
- 「换一批」重新计算；
- 点任意时段标签回填日期与起止时间；
- 提交时若仍被冲突拦截，保留弹窗并自动刷新推荐，用户直接点一条替换即可。

## 二、试听结束自动推进

### 解决什么

顾问约完试听，常常忘了回来把预约和线索状态改掉：预约一直停在「待试听」，线索一直停在「新线索/已跟进」，
续报漏斗因此失真，也没人跟进试听结果。

### 规则

| 项 | 内容 |
|---|---|
| 规则编码 | `AUTO_TRIAL_FOLLOWUP` |
| 模式 | 定时（每 10 分钟一批） |
| 默认 | 关闭，需在「自动化中心」开启 |
| 参数 | `graceMinutes` 宽限时间（默认 30 分钟，留给顾问当场录结果）；`notify` 是否提醒跟进人（默认开） |

执行逻辑：

1. 找出 `TRIAL_TIME` 早于「当前时间 − 宽限时间」且状态仍为 `PENDING` 的试听预约；
2. 预约置为 `DONE`；
3. 关联线索中状态为「新线索 / 已跟进」的推进到「已试听」；已报名、已流失不动；
4. 给线索的跟进人发站内信，列出最近 5 条线索（姓名 + 家长电话），提醒录入试听结果。

> 约试听时线索状态本身就会变成「已试听」，所以第 3 步在多数场景下是 0 条——
> 这不算异常；站内信仍然会发给跟进人，提醒他来录结果，这正是规则的主要价值。

## 三、一键初始化数据库

```bash
node scripts/db-init.mjs --host 127.0.0.1 --port 3306 \
  --user root --password 12345678 --database chameleon
```

- 先建库（不存在时），再按固定顺序执行 `snowy-web-app/src/main/resources/_sql/` 下的脚本；
- 脚本顺序有依赖：**底座表补租户列必须早于按租户写关系数据的菜单脚本**；
- 常见幂等报错（`Duplicate column name`、`already exists` 等）会被忽略，重复执行安全；
- 结束时对关键表做健康检查：`SYS_USER`、`SYS_ROLE`、`SYS_RESOURCE`、`T_TENANT`、`COURSE`、`STUDENT`、`BIZ_EVENT`、`SYS_AUTH_AUDIT`、`DEV_JOB`；
- 已在空库 `chameleon_init_test` 上验证：22 个脚本、0 失败。
