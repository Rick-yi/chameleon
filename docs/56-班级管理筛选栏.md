# 班级管理筛选栏改造

## 参照

按同类产品的班级列表筛选结构改造：状态页签 + 一行无边框筛选 + 快捷筛选标签。

## 布局

1. 顶部班型页签：`一对多` / `一对一`，切换后只加载对应班型。
2. 第二行：左侧「在课 / 已停用」状态页签，右侧「新增班级」。
3. 第三行筛选：
   - 班级名称搜索框；
   - 重置；
   - 班级老师（下拉，无边框）；
   - 关联课程（下拉，无边框）；
   - 教室（下拉，无边框）；
   - 满班（勾选）；
   - 已排课（勾选）。

## 后端筛选参数

`CourseClassPageParam` 新增：

| 参数 | 说明 |
| --- | --- |
| `teacherId` | 授课教师 |
| `classroom` | 教室（模糊匹配） |
| `status` | 启用 / 停用 |
| `hasSchedule` | 是否已排课 |
| `full` | 是否满班（容量>0 且在读人数 ≥ 容量） |

## 交互

- 状态、老师、课程、教室、满班、已排课变化后自动刷新表格并回到第一页，不再需要点「查询」。
- 「重置」恢复默认：一对多 / 在课 / 清空筛选。
- 新增或删除班级后同步刷新班型数量。

## 验证

- 一对多页签表头包含「在学/容量」。
- 一对一页签表头包含「绑定学员」，不显示容量列。
- 状态切到「已停用」正常生效。
- 满班、已排课勾选可触发后端筛选。
- 后端测试 32 个全部通过。
- 前端生产构建通过。

## 构建注意

本地打包时如果 `snowy-web-app/target/snowy-web-app-3.0.0.jar` 已存在，可能不会重新生成；本次已按既有做法先删除旧可执行包再打包，确认新参数已进入 `BOOT-INF/lib/snowy-plugin-course-3.0.0.jar`。
