# 01 · 环境准备

本工程要求 **JDK 17**、Maven、Node.js ≥ 18、MySQL（8.0 / 5.7）、Redis。
以下以 Windows + PowerShell 为主，给出安装要点与自检命令。

> 交付时的本机现状：Maven 3.9.7 ✅、Node v22.14.0 / npm 11.12.0 ✅、JDK **仅 1.8** ❌、MySQL ❌、Redis ❌、Docker ❌。

---

## 1. JDK 17（必须）

Snowy 3.x 基于 Spring Boot 3，`pom.xml` 中 `java.version=17`、编译目标 `<source>17</source>`，**JDK 8 无法编译**。

### 1.1 本工作目录已内置 JDK 17（推荐，不动系统环境变量）

本仓库已经放好一个便携版 **Temurin 17.0.20.1**：

```
.jdk/jdk-17/                     ← JDK 本体（已被 .gitignore 忽略，不入库）
.jdk/set-jdk17.ps1               ← PowerShell 用
.jdk/set-jdk17.cmd               ← cmd 用
.jdk/maven-settings-local.xml    ← 把 Maven 本地仓库固定到工作区内（见 2.2）
```

**cmd 里启用（仅当前窗口生效）**

```bat
.jdk\set-jdk17.cmd
mvn -v
```

**PowerShell 里启用（仅当前窗口生效）**

```powershell
. .\.jdk\set-jdk17.ps1
mvn -v
```

> 若 PowerShell 报"未对文件进行数字签名"，说明该会话执行策略更严。两条出路：
> ① 用上面的 `.cmd` 版本；② 或在脚本前加 `powershell -NoProfile -ExecutionPolicy Bypass -File`。
> 不要为了跑一个脚本去改全局执行策略。

**手动指定（不依赖脚本）**

```powershell
$env:JAVA_HOME = "$PWD\.jdk\jdk-17"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
java -version
```

### 1.2 或者自己装一个

1. 下载 Eclipse Temurin 17（推荐）或 Microsoft Build of OpenJDK 17：
   - Temurin：<https://adoptium.net/temurin/releases/?version=17>
   - 选择 `Windows x64 .msi`，安装时勾选 *Set JAVA_HOME*。
2. 或解压 zip 版到固定目录（例如 `C:\RJ\jdk-17`），手动配置环境变量：
   ```powershell
   setx JAVA_HOME "C:\RJ\jdk-17"
   setx PATH "$env:PATH;C:\RJ\jdk-17\bin"   # 新开终端生效
   ```

**校验**

```powershell
java -version     # 期望：openjdk version "17.x"
mvn -v            # 期望：Java version: 17.x（Maven 用的是 JAVA_HOME 指向的 JDK）
```

**注意（本机已有 JDK 8）**

- 当前 `JAVA_HOME=C:\RJ\jdk1.8`。**不要**让 Maven 用 JDK 8，否则 `mvn` 直接编译失败。
- 若不想改全局环境变量，可只在 IntelliJ IDEA 中指定：
  - `File → Project Structure → Project SDK` 选 17，`Language level` 选 17；
  - `Settings → Build, Execution, Deployment → Build Tools → Maven → Runner → JRE` 选 17；
  - `Settings → Build Tools → Maven → Importing → JDK for importer` 选 17。
- 单次命令行临时指定（不写全局变量）：
  ```powershell
  $env:JAVA_HOME = 'C:\RJ\jdk-17'; mvn -v
  ```

## 2. Maven

- 本机已有 **Apache Maven 3.9.7**（`C:\RJ\apache-maven-3.9.7`），满足要求。
- 建议配置国内镜像以加速依赖下载（可选）：编辑 `C:\RJ\apache-maven-3.9.7\conf\settings.xml`，在 `<mirrors>` 中加入阿里云 `https://maven.aliyun.com/repository/public`。
- 首次构建会下载大量依赖（Spring Boot 3 + Sa-Token + OpenSAML 等，约数百 MB），耗时较长；仓库同时配置了 `repository.mulesoft.org` 与 `build.shibboleth.net` 两个境外仓库，网络受限时会较慢（Maven 会超时后回落到镜像）。

### 2.1 正常开发（IDEA / 普通终端）

用你自己的 `~/.m2` 仓库即可，不需要额外参数：

```powershell
mvn clean package -DskipTests
```

IDEA 里只要把 Project SDK、Maven Runner JRE 都设成 `.jdk\jdk-17` 即可。

### 2.2 需要"仓库也放工作区内"时

如果你的环境不允许写 `~/.m2`（例如受限沙箱），用仓库里自带的 settings 把本地仓库固定到 `.m2-repo/`：

```powershell
mvn -s .jdk\maven-settings-local.xml clean package -DskipTests
```

该文件只做两件事：`<localRepository>` 指向工作区内 `.m2-repo/`，并把 `*` 镜像到阿里云。`.m2-repo/` 已被 `.gitignore` 忽略。

## 3. Node.js / npm

- 本机已有 **Node v22.14.0** 与 **npm 11.12.0**，满足 `≥18` 要求。
- 建议配置镜像加速（可选）：
  ```powershell
  npm config set registry https://registry.npmmirror.com
  ```
- 前端**没有提交 lockfile**，`npm install` 会按 `package.json` 的精确版本解析（绝大部分依赖锁定为精确版本号，漂移风险较小）。

## 4. MySQL（8.0 或 5.7）

**安装**（任选其一）

- MySQL Installer：<https://dev.mysql.com/downloads/installer/>，选 *Server only* 或 *Developer Default*；
- 免安装 zip 版：解压后 `mysqld --initialize-insecure` 再 `mysqld --install` 注册服务。

**要点**

1. 记住 `root` 密码。工程默认按 `root` / `12345678` 连接（`application.properties`），**不一致就改配置，不是改数据库**。
2. 字符集使用 `utf8mb4`（脚本内含 `SET NAMES utf8mb4`）。
3. 创建业务库：
   ```sql
   CREATE DATABASE chameleon DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
   ```
4. 时区：工程 Jackson 配置为 `GMT+8`，MySQL 保持默认即可。

**校验**

```powershell
mysql -uroot -p -e "SELECT VERSION(); SHOW DATABASES LIKE 'chameleon';"
```

## 5. Redis

工程用于缓存、Sa-Token 会话、easy-trans 等，**必须启动**。

**Windows 上的选择**（本机没有 Docker，也没有官方 Windows 版 Redis）

| 方案 | 说明 |
|---|---|
| WSL2 + `apt install redis-server` | 最接近生产，推荐 |
| Memurai（Redis 兼容的 Windows 服务） | 安装即用，免费开发版 |
| tporadowski/redis 的 Windows 移植版 | 社区维护的 5.x/7.x 移植 |
| Docker Desktop + `redis:7.0` | 若后续安装 Docker 则最省事 |

**默认连接参数**（来自 `application.properties`）

| 参数 | 值 |
|---|---|
| host | `127.0.0.1` |
| port | `6379` |
| password | 空 |
| database | `1` |

**校验**

```powershell
redis-cli ping           # 期望 PONG
redis-cli -n 1 dbsize    # 能连上 1 号库即可
```

## 6. 一键自检

```powershell
java -version
mvn -v
node -v
npm -v
mysql -uroot -p -e "SELECT VERSION();"
redis-cli ping
# 端口占用检查（82 后端 / 81 前端 / 3306 / 6379）
foreach ($p in 81,82,3306,6379) { "$p => " + ((Test-NetConnection -ComputerName 127.0.0.1 -Port $p -WarningAction SilentlyContinue).TcpTestSucceeded) }
```
