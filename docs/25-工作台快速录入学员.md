# 25 · 工作台快速录入学员

> 前台接待最常见的动作是「家长带孩子来咨询 → 当场建档 → 选课包 → 收款」。
> 原先要跑「学员管理 → 新增学员 → 报名 → 收款台」四步，现在工作台一个弹窗完成。

---

## 一、入口

- 工作台页头新增主按钮「录入学员」；
- 快捷入口第一项新增「录入学员」（橙色图标），点击直接打开弹窗；
- 两个入口都按 `/student/add` 权限控制，没有权限不显示。

## 二、弹窗字段

分三段，手机端自动单列：

### 学员信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 学员姓名 | 是 | |
| 性别 | 否 | 男/女，默认男 |
| 生日 | 否 | 日期选择 |
| 校区 | 否 | 默认当前用户所属校区；多校区可选 |

### 家长信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 家长姓名 | 否 | |
| 家长手机 | 是 | 11 位手机号校验，用于联系与续费 |

### 报名与收款

| 字段 | 说明 |
|---|---|
| 报名课包 | 选填；不选则只建档，不生成订单 |
| 立即收款 | 选课包后默认开启；关闭则只生成待收款订单 |
| 收款渠道 | 现金 / 微信 / 支付宝 / 线下转账（均为主观登记，不做线上支付对接） |
| 实收金额 | 默认课包价格，可改（优惠/补差） |
| 备注 | 选填，记录意向、优惠说明等 |

## 三、后端流程

新增 `POST /student/quickEnroll`，一个事务内完成：

1. 创建学员档案（复用 `StudentService.add`，含套餐学员数上限校验）；
2. 选择课包时创建订单（复用 `StudentOrderService.add`）；
3. 开启立即收款时登记收款（复用 `StudentOrderService.offlinePay`，生成课时账户与入账流水）；
4. 任一步失败整体回滚，不会出现「学员建了、订单没建」的半成品。

接口权限：方法上校验 `/student/add`；路径加入业务接口白名单，避免为每个租户单独补授权。

收款渠道同时放开到 `CASH / OFFLINE / WECHAT / ALIPAY`（均为手工登记，线上自动支付仍未接入），订单页、学员详情、移动端收款台的下拉选项同步补齐。

## 四、验证

| 场景 | 结果 |
|---|---|
| 建档 + 课包 + 微信收款 | 订单 `PAID`、渠道 `WECHAT`、实收 3600、课时账户 +22（含赠课 2） |
| 建档 + 课包 + 不收款 | 生成 `UNPAID` 订单，出现在工作台「待收款订单」 |
| 只建档不选课包 | 只创建学员，不产生订单 |
| 未选课包却开启收款 | 后端拒绝：「请选择课包后再登记收款」 |
| 界面提交 | 工作台按钮/快捷入口均可打开弹窗，提交后提示并刷新工作台 |
| 手机端 | 弹窗单列表单、渠道选项自动换行，可正常提交 |
