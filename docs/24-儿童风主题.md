# 24 · 儿童风主题（果子绿 + 爱马仕橙）

> 把原先「企业蓝 + 小圆角」的观感，换成更适合教培场景的儿童友好风格：明亮、圆润、有温度。

---

## 一、配色

| 角色 | 色值 | 用在哪 |
|---|---|---|
| 主色 · 果子绿 | `#4BB964` | 主按钮、链接、选中页签、输入框聚焦、图表主序列 |
| 主色深 | `#3B9A50` | 按钮 hover/active、文字链接 |
| 强调 · 爱马仕橙 | `#F37021` | 侧边栏选中项、警告/待处理标签、图表次序列、登录页渐变 |
| 成功 | `#2BA471` | 已点名、在读、成功提示 |
| 危险 | `#E5484D` | 退费、删除、缺勤 |
| 背景 | `#F4F9F0` | 页面底色（奶油绿） |
| 卡片 | `#FFFFFF` | 内容卡片 |
| 边框 | `#E3EADE` | 卡片、输入框（偏暖） |

侧边导航改为深果子绿 `#123B2B`，选中项用爱马仕橙，避免绿色按钮和绿色导航混在一起。

## 二、圆角与形状

| 元素 | 圆角 |
|---|---|
| 卡片 / 弹窗 | 18–20px |
| 按钮 | 12–16px（大号按钮接近胶囊） |
| 输入框 / 下拉 / 日期 | 10–12px |
| 标签 | 999px（胶囊） |

## 三、配置位置

| 文件 | 作用 |
|---|---|
| `snowy-admin-web/src/App.vue` | Ant Design Vue `ConfigProvider`：主色、警告色、圆角、侧边栏/菜单组件令牌 |
| `snowy-admin-web/vite.config.mjs` | `enterpriseToken`：Ant Less 变量（按钮、输入、菜单、圆角） |
| `snowy-admin-web/src/config/index.js` | 默认主题色改为 `#4BB964` |
| `snowy-admin-web/src/config/settingConfig.js` | 主题色预设新增「果子绿」「爱马仕橙」并置顶 |
| `snowy-admin-web/src/style/enterprise.less` | CSS 变量、侧边栏深绿/橙色选中、组件级配色 |
| `snowy-admin-web/src/views/auth/login/login.less` | 登录页绿→橙渐变与气泡装饰 |
| 报表页 `color: [...]` | 图表序列改为绿/橙/红组合 |

## 四、验证

- 主色令牌：`--primary-6 = #4bb964`，主按钮背景 `rgb(75, 185, 100)`；
- 卡片圆角：`--radius-card = 18px`；
- 侧边栏背景 `rgb(18, 59, 43)`，选中项 `rgb(243, 112, 33)`；
- 登录页、工作台、学员、排课、财务报表截图确认无错位；
- 控制台无报错。

> 主题色仍可在「设置 → 主题色」里切换；果子绿和爱马仕橙排在预设最前面。
