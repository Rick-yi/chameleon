# 班级容量展示

> 日期：2026-10-27

## 一、需求

班级列表原来只显示在学人数，看不到班级容量和剩余名额。前台给学员分班时容易把班加超，必须点开编辑弹窗才知道容量。

验收标准：

- 列表列改为「在学/容量」，直接显示 `5 / 15`；
- 鼠标悬停提示「剩余 N 个名额」或「已满班」；
- 满班红色、80% 以上橙色、其余蓝色；
- 未设置容量时显示 `5 / -`，用默认色；
- 新增/编辑班级、学员列表、排课入口不变。

## 二、实现

`/course/class` 列表的学员列改为：

- 文案：`studentCount / capacity`；
- 颜色：`capacityColor(record)`；
- 提示：`capacityTitle(record)`。

数据来自现有 `GET /course/class/page`，`studentCount` 后端已批量统计，没有新增接口。

加人时增加二次确认：当前人数 + 本次选择人数超过容量时，弹出「超出班级容量」提示，说明超出几人，可取消或仍然加入；加入成功后同步刷新当前弹窗人数和背后的班级列表。

## 三、验证

- PC 班级管理页表头出现「在学/容量」；
- 演示班级显示 `5 / 15`；
- 本地临时把班级容量改为 5，选择 1 名学员加入，弹出「超出班级容量」确认框；取消后未写入数据，容量已恢复为 15；
- 前端构建通过（5418 个模块）；
- 无前端运行异常。

## 四、边界

- 只做展示，不在加人时强制拦截超容量；真正的容量校验仍需要后端和分班流程配合。
- 未设置容量的存量班级不会误报满班。
- 本次不发布生产。
