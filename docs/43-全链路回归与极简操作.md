# 全链路回归与极简操作

> 日期：2026-10-26
> 范围：PC 学员/报名/收款/订单，APP 学员名册/收款台/报名弹窗/老师入口
> 目标：把上一轮没有消化完的 APP 对齐问题补齐，并把高频操作压缩到“能自动带出的不手选、能点一下就少点一下”。

## 一、这次补齐的真实缺口

| 缺口 | 处理 |
|---|---|
| APP 学员名册只能给已有学员报名，不能新增 | 名册顶部和空态都加「新增学员」，直接打开同一套建档+课包/班级+收款流程 |
| APP 订单详情只是报名成功页，从收款台查不到 | 收款台订单卡片可直接点开订单详情抽屉，展示学员、校区、班级、课时、金额、渠道、经办人 |
| PC 收款台没有完整订单详情 | 订单号可点开详情且保留复制入口，操作列保留「详情」，共用同一个订单详情组件 |
| 校区分了，班级没按校区过滤 | 班级选项增加校区字段，按报名校区过滤；切换校区时自动清掉不属于该校区的班级 |
| 只有一个课包/班级仍要手选 | 只有一个课包时自动带出；当前校区只有一个班时自动选中 |
| 每次报名都要重选收款方式 | 记住上一次收款渠道，下次报名默认带出 |
| 继续录入会丢掉校区和收款方式 | 「继续录入」保留校区、收款方式和上次的默认选项 |
| 取消报名后下次仍提示恢复草稿 | 取消/完成后立即关闭草稿写入；自动带出的课包/校区不再算“用户填过”的草稿 |
| 待支付订单把未收金额显示成优惠 | 订单详情只在已支付/已退费时计算优惠，待支付显示“-” |
| APP 教学视角看不到老师管理 | 教学视角快捷操作增加「老师管理」，仅管理员显示；同时放开 `/app/teacher` 视角访问 |

## 二、少一步操作的具体效果

### 1. APP 新增学员

之前：APP 首页 → 快捷操作 → 录入学员。

现在：APP 学员名册 → 新增学员；如果名册为空，空态直接给按钮。

学员详情抽屉里也补了「报名 / 续费」，看完课时余额可以直接续费，不用退回列表找按钮。

### 2. 看订单详情

之前：收款台只能看到学员、课包、金额、状态；要核对课时/优惠/经办人只能去别处找。

现在：

- APP：点订单卡片直接打开订单详情；
- PC：点订单号，或操作列「详情」；订单号旁的复制图标仍保留；
- 支持 `/student/order?orderId=xxx`、`/app/cashier/orders?orderId=xxx` 直接打开订单详情；
- 待收款订单在详情里直接「去收款」，已收款订单可「查看学员」。

### 3. 报名表单

只有一个课包、一个校区、一个班时，打开报名弹窗后：

- 校区自动选中；
- 课包自动选中，并带出价格、正课/赠课、有效期和班级；
- 当前校区只有一个班时自动选中，班级选项显示「班级 · 教室 · 授课老师」；
- 用户只需要填学员姓名（家长手机选填），点「核对收款」→「确认收款」。

多课包/多班级时不会乱猜，仍保留下拉选择。

### 4. 草稿与取消

- 只有用户实际填了姓名/家长手机才写草稿；
- 自动带出的课包、校区不触发草稿提示；
- 点取消/完成后不会再被表单 watcher 重新写回草稿；
- 页面意外刷新时仍能恢复用户真正填过的内容。
