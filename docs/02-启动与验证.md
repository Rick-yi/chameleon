# 02 · 启动与验证

前置：已完成 [01-环境准备.md](01-环境准备.md)，`java -version` 为 17，MySQL 与 Redis 均可连。

---

## 步骤 1 · 建库并导入初始数据

初始化脚本：`snowy-web-app/src/main/resources/_sql/snowy_mysql.sql`
（脚本**只含建表与初始化数据**，没有 `CREATE DATABASE` / `USE` 语句，库名由你决定。）

```powershell
# 建库
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS chameleon DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"

# 导入（Windows 下用 cmd 的重定向更稳；PowerShell 也可用 Get-Content 管道）
cmd /c "mysql -uroot -p chameleon < snowy-web-app\src\main\resources\_sql\snowy_mysql.sql"
```

验证：

```sql
USE chameleon;
SHOW TABLES;                       -- 应有 SYS_USER / SYS_ROLE / DEV_CONFIG / SYS_RESOURCE ...
SELECT ACCOUNT, NAME, ENABLE_FLAG FROM SYS_USER;
-- 期望看到 superAdmin(超管) 与 bizAdmin(业管)
SELECT CONFIG_KEY, CONFIG_VALUE FROM DEV_CONFIG WHERE CONFIG_KEY IN ('SNOWY_SYS_NAME','SNOWY_SYS_COPYRIGHT','SNOWY_SYS_DEFAULT_PASSWORD_FOR_B');
-- 期望：Chameleon / Chameleon ©2026 · Powered by Snowy (xiaonuo.vip) / Chameleon@2026!
```

## 步骤 2 · 检查/修改连接配置

文件：`snowy-web-app/src/main/resources/application.properties`

```properties
server.port=82
spring.application.name=chameleon
spring.datasource.dynamic.datasource.master.url=jdbc:mysql://localhost:3306/chameleon?...   # 库名
spring.datasource.dynamic.datasource.master.username=root                                    # 账号
spring.datasource.dynamic.datasource.master.password=12345678                                # 密码
spring.data.redis.host=127.0.0.1
spring.data.redis.port=6379
spring.data.redis.database=1
```

> 想保留个人配置又不动仓库文件：在同目录新建 `application-local.yml`（`spring.profiles.active=local` 会自动加载），内容按需覆盖，例如
> ```yaml
> spring:
>   datasource:
>     dynamic:
>       datasource:
>         master:
>           password: 你的密码
>   data:
>     redis:
>       password: 你的redis密码
> ```
> 并把它加入 `.gitignore`。

## 步骤 3 · 启动后端

**方式 A：IDEA 运行（推荐调试）**

- 主类：`snowy-web-app/src/main/java/vip/xiaonuo/Application.java`，包名 `vip.xiaonuo`
- 运行 `Application.main()`，控制台出现 `Started Application in x seconds` 即成功
- 需确认 IDEA 的 JDK / Maven Runner JRE 均为 17

**方式 B：命令行打包运行**

```powershell
# 仓库根目录
mvn clean package -DskipTests
java -jar snowy-web-app/target/snowy-web-app-3.0.0.jar
```

启动成功的判据：

```powershell
# 后端端口
Test-NetConnection 127.0.0.1 -Port 82
# 打开接口文档（Knife4j，basic 账号 admin / 123456）
start http://localhost:82/doc.html
```

## 步骤 4 · 启动前端

```powershell
cd snowy-admin-web
npm install          # 首次较慢
npm run dev          # 默认 81 端口，--host 0.0.0.0
```

- 访问 <http://localhost:81>
- 前端所有 `/api/**` 请求由 Vite 代理到 `VITE_API_BASEURL`（`.env.development` 中为 `http://127.0.0.1:82`），并去掉 `/api` 前缀（见 `vite.config.mjs`）

生产构建：

```powershell
npm run build        # 产物在 snowy-admin-web/dist
```

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 后端启动报 `UnsupportedClassVersionError` / 编译报 `无效的目标发行版: 17` | 用的还是 JDK 8。检查 `JAVA_HOME` 与 IDEA 的 SDK / Maven Runner JRE |
| 启动报 `Communications link failure` / `Access denied for user 'root'` | MySQL 未启动或账号密码与 `application.properties` 不一致 |
| 启动报 `Unknown database 'chameleon'` | 步骤 1 未建库，或 JDBC URL 里的库名与你实际建的库名不同 |
| 启动报 Redis 连接失败 | Redis 未启动；或密码/端口/库号不一致 |
| `Port 82 was already in use` | 改 `server.port`，同时改前端 `.env.development` 的 `VITE_API_BASEURL` |
| 前端页面能开但接口全部 404/超时 | 后端没起，或 `VITE_API_BASEURL` 与后端端口不一致 |
| 登录页验证码不显示 | 上游种子数据里 `SNOWY_SYS_DEFAULT_CAPTCHA_OPEN_FLAG_FOR_B` 的值写成了中文标签（上游数据小瑕疵），前端按"非 true"处理即不显示验证码，不影响登录 |
| `/doc.html` 404 | 确认 `knife4j.enable=true`（默认开启）、后端已启动、访问的是后端端口 |
| `mvn package` 卡在下载依赖 | 换国内 Maven 镜像或配置代理（`repository.mulesoft.org` 等境外仓库可能较慢） |
| 数据库中文乱码 | 建库时未用 `utf8mb4`，或连接串缺少 `characterEncoding=utf-8` |

## 回滚 / 重建

- 想清空重来：`DROP DATABASE chameleon;` 后重做步骤 1；
- 想清 Redis 会话：`redis-cli -n 1 FLUSHDB`。
