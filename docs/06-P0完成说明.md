## 三、开通租户时发生了什么

调用 `POST /platform/tenant/add` 后，同一事务内完成：

1. 写入 `T_TENANT`（编码、套餐、到期时间）；
2. 创建总部 `COMPANY` 与默认校区 `DEPT`；
3. 创建机构管理员账号（密码 SM3 哈希）；
4. 创建机构管理员角色（编码 `superAdmin`，租户内有效）；
5. 复制演示租户超管角色的资源授权（系统管理 + 教务运营，排除平台运营菜单）；
6. 授权用户 → 角色；
7. 从 `demo` 租户复制 `DEV_CONFIG` 与 `DEV_DICT`，并把 `SNOWY_SYS_NAME` 改为新机构名称。

新租户管理员登录后即可看到系统管理、教务运营菜单，不需要再手工建角色/授权。

## 四、退费规则（重要）

- 课时账户仍是“学员 × 课程”一个账户；
- 每个订单独立记录 `CONSUMED_LESSONS`、`REFUNDED_LESSONS`；
- 消课按订单创建时间先进先出分摊（含赠课）；
- 退费申请/审批时按该订单最新消耗重算：
  - 可退课时 = 订单购买课时 − 该订单已消耗的购买课时；
  - 退费金额 = 可退课时 ×（订单实付 ÷ 订单购买课时）；
  - 赠课不可退，随订单作废；
- 确认退款只扣减该订单对应的总课时/剩余课时，**不会清零其他订单的课时**；
- 支持撤销退费：待退款状态撤销后账户解冻。

## 六、支付（v1 范围）

- v1 不接微信支付/支付宝，不提供线上支付回调；
- 前台/财务在学员详情页对未支付订单执行“线下收款”，登记渠道（线下转账/现金）和实收金额；
- 原 `/student/order/payCallback` 保留为联调入口，正式接入支付网关时替换为带签名校验的回调；
- v1 上线前需明确：线下收款是否需要收款凭证附件、是否允许部分收款。
