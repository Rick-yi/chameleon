# APP 收款台搜索

> 日期：2026-10-27

## 一、需求

前台在 APP 收款台找一笔订单时，当前只能按「待收款 / 已收款 / 退费单」翻，列表最多 50 条；家长报姓名或手机号时，需要来回切页签找。

验收标准：

- 一个搜索框同时支持学员姓名、家长手机、订单号；
- 订单和退费单共用关键词；
- 搜索无结果时显示「没有匹配的订单 / 退费单」；
- 搜索时不清空顶部状态数量，避免把搜索结果数误当成全部待办；
- 清空关键词后能回到当前状态全部列表。

## 二、实现

`/app/cashier/orders` 顶部新增搜索框，复用后端已有查询参数：

- 订单：`GET /student/order/page?searchKey=...`
- 退费：`GET /student/refund/page?searchKey=...`

后端订单搜索已支持：

- 学员姓名/家长手机模糊匹配；
- 订单号精确匹配。

前端只在关键词非空时传参；搜索时不覆盖顶部全局状态计数。

## 三、验证

- 390px APP 宽度下搜索框正常显示；
- 搜索「李小红」有结果；
- 搜索不存在的学员显示无结果提示；
- 前端构建通过（5418 个模块）；
- 无前端运行异常。

## 四、边界

- 当前仍是单页 50 条，搜索走服务端；分页/加载更多未做。
- 退费单搜索复用同一关键词，但退费单没有订单号字段，主要按学员姓名/手机匹配。
- 本次不发布生产。
