# 33 · 学员列表移动卡片

> UI/UX 审计发现：390px 下学员表格内容宽 1190px，剩余课时、课包到期、班级、待收款都在横向滚动区，首屏只剩姓名和固定操作列。
> 这一轮把手机端改为卡片列表，桌面表格保持不变。

---

## 一、改造内容

### 1. 手机卡片

每张卡片首屏包含：

- 姓名 + 状态标签；
- 剩余课时（未报名显示“未报名”，低课时/无课时分色）；
- 家长姓名 + 手机号，提供「拨号」直接调起电话；
- 课包到期、所在班级、待收款三项关键数据；
- 「详情」「报名」「更多」三个操作，高度 44px。

### 2. 桌面表格不变

- ≥992px 仍使用原表格，列、排序、分页、操作列完全不变。
- 手机端隐藏表格，改为独立卡片分页，避免同一页面渲染两套数据。

### 3. 筛选与分页

- 手机端「查询」「重置」走卡片列表的独立分页，默认每页 10 条。
- 新增学员后回到第 1 页，确保能看到刚建档的记录。
- 搜索、状态筛选、从报表带参进入都复用同一套查询条件。

### 4. 触控与输入

- 手机端卡片操作按钮 44px，筛选输入 16px，页面主按钮 44px。
- 卡片操作区两枚按钮等宽，「更多」保留 44px 点击区。

## 二、验证结果

| 场景 | 结果 |
|---|---|
| 390px 学员列表 | 8 张卡片，无横向溢出，首屏可见剩余课时/到期/班级/待收款 |
| 375px / 390px | 页面 scrollWidth = 视口宽度，无横向滚动 |
| 搜索“测试报名” | 卡片列表过滤为 1 条 |
| 卡片按钮 | 详情/报名/更多均 44px 高 |
| 1280px 桌面 | 仍为表格，11 列完整，无溢出 |
| 详情入口 | 卡片「详情」沿用原抽屉逻辑，手机端全宽 |

## 三、边界与缺口

- 本地只有 8 名学员，未验证超过 10 条时的手机分页翻页；生产 41 名学员可在发布后验证。
- 未做真实前台可用性测试；「拨号」在桌面隐藏，只在手机卡片出现。
- 卡片列表目前是“一屏一张”，后续可考虑密度切换（紧凑/舒适）。
- 桌面表格的列配置、批量操作仍未做。
