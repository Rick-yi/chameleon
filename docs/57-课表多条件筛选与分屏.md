# 课表多条件筛选与分屏查看

## 一、多条件筛选

课表主工具栏新增一行筛选：

- 校区
- 课程
- 班级（支持搜索，一对一班显示绑定学员）
- 教师（支持搜索）
- 教室
- 点名状态（未点名 / 部分点名 / 已点名）
- 重置

筛选变化立即刷新当前周课表，不需要再点查询按钮。

后端 `/course/schedule/week` 新增参数：

| 参数 | 说明 |
| --- | --- |
| `campusId` | 校区 |
| `courseId` | 课程 |
| `attendStatus` | 点名状态 NONE / PARTIAL / DONE |

课程、校区、点名状态在课节填充班级/报名人数/点名人数后过滤，保证与页面展示口径一致。

## 二、分屏查看

新增「分屏查看」视图：

- 默认 1 个窗口，最多 4 个窗口；
- 每个窗口独立选择教师、班级、教室；
- 所有窗口共用当前周，切换上一周/下一周时一起刷新；
- 窗口内按天列出课节，显示时间、班级、教师、教室、点名状态；
- 点击课节直接进入点名；
- 有冲突的课节仍标红；
- 窄屏（<1100px）自动改为单列。

## 三、验证

- 课表接口筛选：班级、教室、校区、课程、点名状态均返回正确结果。
- 页面工具栏：周视图 / 日视图 / 教师视图 / 分屏查看，六个筛选项和重置均存在。
- 分屏：默认 1 个窗口，连续添加后最多 4 个，每个窗口都有教师/班级/教室筛选。
- 后端测试 32 个全部通过。
- 前端生产构建通过。

## 四、说明

- 分屏窗口的筛选不共享主工具栏条件，窗口之间也互不影响，便于同时对比不同教师或教室。
- 主工具栏筛选在分屏视图下隐藏，避免两套条件互相干扰。
