# 10 · 界面设计规范（企业级）

> 目标：让 chameleon 的界面从「AntD 默认样式的拼装」变成统一的**企业控制台**观感——
> 冷灰底、细边框、紧凑信息密度、弱装饰、层级清晰。所有页面共用同一套令牌与结构。

---

## 一、设计取向

| 维度 | 取向 | 说明 |
|---|---|---|
| 色彩 | 冷灰底 + 沉稳企业蓝 | 主色 `#1668dc`（比默认 `#1677ff` 更深更稳），语义色统一降饱和（成功 `#2ba471` / 警告 `#d89614` / 错误 `#e5484d`） |
| 装饰 | 弱化 | 去掉 emoji、去掉大面积彩色块、去掉立体阴影，改用 1px 细边框表达层级 |
| 密度 | 紧凑 | 表格行高 40px、表头 13px/600、表单控件 32px |
| 结构 | 固定骨架 | 每个业务页 = 页头 + 工具栏 + 内容区 三段式 |
| 数字 | 等宽 | 表格与统计块统一 `tabular-nums`，金额列不再左右跳动 |

## 二、令牌（Token）

### 1. Ant Design 变量（`vite.config.mjs` → `enterpriseToken`）

AntD 4 的 Less 是带变量编译的（`modifyVars`），因此**换肤只需覆盖变量**，全站组件自动生效：

```js
modifyVars: { ...v3Token, ...enterpriseToken }
```

主要令牌：

| 类别 | 令牌 | 取值 |
|---|---|---|
| 主色 | `primary-color` / `-hover` / `-active` / `-outline` | `#1668dc` / `#3c85f0` / `#0e42b2` / `#b3d1f5` |
| 语义色 | `success-color` / `warning-color` / `error-color` | `#2ba471` / `#d89614` / `#e5484d` |
| 文字 | `text-color` / `text-color-secondary` / `heading-color` | `#1d2129` / `#4e5969` / `#1d2129` |
| 边框 | `border-color-base` / `border-color-split` | `#e5e6eb` / `#f0f1f3` |
| 背景 | `background-color-light` / `-base` / `layout-body-background` | `#f7f8fa` / `#f2f3f5` / `#f5f6f7` |
| 圆角 | `border-radius-base` / `border-radius-sm` / `tag-border-radius` | `4px` / `2px` / `2px` |
| 表格 | `table-header-bg` / `table-row-hover-bg` / `table-padding-vertical` | `#f7f8fa` / `#f4f7fd` / `10px` |
| 控件 | `input-height-base` / `btn-border-radius-base` | `32px` / `4px` |
| 导航 | `layout-sider-background` / `menu-item-height` / `menu-item-font-size` | `#1e2330` / `38px` / `13px` |

### 2. Snowy 自身变量与组件样式（`src/style/enterprise.less`）

Snowy 组件用的是 `:root` CSS 变量，主题层在 `index.less` 中**最后 import**，保证覆盖优先级：

- 变量对齐：文字/边框/背景与 AntD 令牌同源
- 组件规整：卡片（细边框+轻阴影）、表格（去竖线、浅表头、紧凑行高）、表单（标签右对齐、间距收紧）、按钮（无立体阴影）、标签（2px 圆角）、弹窗/抽屉（统一头部与圆角）、菜单（深色侧栏）
- 通用类：`page-header` / `ent-toolbar` / `ent-body` / `ent-stat` / `ent-list` / `ent-shortcut` / `ent-note` / `ent-empty` / `ent-schedule-card`

## 三、页面结构（三段式）

每个业务页统一为：

```vue
<page-header title="学员管理" desc="学员档案、课时账户与报名入口">
	<template #extra>
		<a-button type="primary">新增学员</a-button>   <!-- 主操作在右上角 -->
	</template>
</page-header>

<div class="ent-toolbar">        <!-- 筛选条件：横向、紧凑 -->
	<a-form layout="inline"> ... </a-form>
</div>

<div class="ent-body">           <!-- 内容区：表格 / 卡片 -->
	<s-table ... />
</div>
```

要点：
- **主操作放页头右侧**，不再塞在表格右上角（避免"筛选区和按钮打架"）
- 筛选区一律 `layout="inline"`，不再用三列栅格
- 空状态用轻量文字（`.ent-empty`），不用大插画，避免卡片高度失衡
- 提示信息用 `.ent-note` 轻提示条，不用整块蓝色 Alert

### PageHeader 组件

`src/components/PageHeader/index.vue`：标题 + 说明 + 右侧操作区，全站共用。

## 五、权限与降级

后端对越权接口返回 HTTP 200 + `body.code = 403`，前端必须区分「页面主数据被拒」与「辅助数据被拒」：

| 场景 | 处理 |
|---|---|
| 页面主数据 403 | 全局置 `forbidden`，布局层渲染「无权访问」结果页（`a-result status="403"`），而不是白屏；路由切换时复位 |
| 辅助数据 403 | 请求带 `skipForbidden: true`，静默失败、不弹提示、不触发整页无权限（用于首页统计卡片等） |
| 菜单里没有的路由 | 落到全局 404 页（`layout/other/404.vue`），提示「页面不存在」而不是空白 |

首页卡片按角色渲染，避免出现越权空白卡片：

- 超管专属（`superAdmin`）：业务数据、运维一览、基础工具
- 平台运营专属（`platformAdmin`）：周访问量（`/dev/log/**` 为平台接口）
- 两者都无权限时直接不渲染该卡片，而不是渲染一个取不到数的空壳

文案与编码：列表里不要直接展示后端枚举编码（`OFFLINE`/`WECHAT`/`CASH`），
统一走 `src/utils/payChannel.js` 的 `payChannelText()` 转中文；同样适用于表格列与图表图例。

## 六、交互细则

### 1. 操作列收敛（`TableMore`）

一列里超过 2 个操作就会变成一串蓝色链接，视觉噪声大。统一规则：

- 保留 **1~2 个主操作** 用文字链接（详情、报名、跟进、排课……）
- 其余（编辑、删除、试听、转学员等）收进 **「更多」下拉**（`src/components/TableMore/index.vue`）
- 危险操作在下拉里用 `danger: true`，由组件统一弹二次确认（`Modal.confirm`）

### 2. 页头只能有一个

全局页头 `layout/components/pageBar.vue` 会按路由渲染标题；页面自己用了 `<page-header>` 时，
必须把路径加进 `CUSTOM_HEADER_PATHS`，否则会出现双标题。

### 3. 统计卡口径要对得上数据源

订单与退费单是两张表，指标必须分别取（收款台：待收款/已收款取订单，待审批退费/已退费单取退费单），
否则「已退费」这类卡片会永远是 0。

### 4. 少让用户点一次

- 点名消课：进入页面自动定位到最近有排课的一天，并选中第一节课，直接看到名单
- 日期默认按**本地时区**计算（不要用 `toISOString()`，东八区凌晨会回退到昨天）

### 5. 课表网格

课表用 `.sched-*` 系列类名（`.sched-grid` / `.sched-head` / `.sched-cell` / `.sched-card-*`），
颜色一律取主题变量；今天所在的列用 `.is-today` 高亮，不要写死 `#1677ff`、`#f0f0f0` 这类硬编码色。

## 七、首页

系统首页右上是轮播位。后端在未配置轮播图时会返回一张固定占位大图，
前端据此判定「未配置」并渲染**快捷入口**卡片（工作台 / 收款台 / 学员管理 / 排课课表）+ 机构问候语，
避免出现与产品无关的大色块占位图。

## 九、约定与禁忌

1. **不要用 emoji 当图标**：统一用 `@ant-design/icons-vue`
2. **不要用整块彩色 Alert 做常规提示**：用 `.ent-note`；`a-alert` 仅用于真正的错误/警告
3. **不要在表格里写死颜色**：状态用 `a-tag` 的语义色，金额用等宽数字
4. **新增页面必须带 `page-header`**：标题说清"这是什么页"，说明说清"这页干什么"
5. **新增表单不要让用户手填 id**：一律下拉选择
6. 卡片阴影只用 `0 1px 2px rgba(29,33,41,.04)`，不要用彩色阴影
7. **不要在页面里写死颜色**：统一用 `enterprise.less` 的 CSS 变量（`--primary-6`、`--border-color-split`、`--text-color-secondary` 等）
8. **操作列不要超过 2 个可见操作**，其余进「更多」下拉
