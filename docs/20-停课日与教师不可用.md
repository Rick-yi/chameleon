# 20 · 停课日与教师不可用时段

> 课表从「能排」走向「排得对」：节假日不再照排，老师请假/教研的时间也不会被推荐或占用。

---

## 一、停课日（节假日）

### 数据与接口

新增 `COURSE_SCHEDULE_CLOSURE` 表（租户隔离）：

| 字段 | 说明 |
|---|---|
| `CLOSURE_DATE` | 停课日期（唯一：租户 + 校区 + 日期） |
| `NAME` | 名称，如「国庆节」「校区活动」 |
| `REMARK` | 备注 |
| `CAMPUS_ID` | 校区，空表示全机构 |

接口（读写分别复用「排课分页」「手动排课」的权限码）：

- `GET /course/schedule/closure/list?startDate=&endDate=`
- `POST /course/schedule/closure/add`
- `POST /course/schedule/closure/delete`

### 生效范围

| 场景 | 行为 |
|---|---|
| 手动排课 / 调课 | 目标日期是停课日 → 直接拒绝，提示「2026-11-04 是停课日【校区活动】，不能排课」 |
| 按周模板批量生成 | 命中停课日的课节跳过，计入 `skippedCount`，并在 `skipReasons` 里列出「2026-11-04 停课日【校区活动】，已跳过」 |
| 直接排课 | 同上 |
| 排课助手推荐 | 停课日整天不产生候选 |
| 周视图 | 表头显示橙色「停课」标签 |

停课日只跳过、不算冲突，其余周次正常生成。

---

## 二、教师不可用时段

### 数据与接口

新增 `COURSE_TEACHER_UNAVAILABLE` 表（租户隔离）：

| 字段 | 说明 |
|---|---|
| `TEACHER_ID` | 教师 |
| `START_TIME` / `END_TIME` | 不可用区间 |
| `REASON` | 原因（请假、教研、跨校区通勤等） |

接口：

- `GET /course/schedule/teacherUnavailable/list?teacherId=&startTime=&endTime=`（`teacherId` 可空，空则返回全部教师）
- `POST /course/schedule/teacherUnavailable/add`
- `POST /course/schedule/teacherUnavailable/delete`

### 生效范围

| 场景 | 行为 |
|---|---|
| 手动排课 / 调课 | 时段与不可用区间重叠 → 冲突提示「教师【王老师】在 2026-11-05 09:00-10:30 不可用（教研）」 |
| 批量生成 / 直接排课 | 同上，在预览阶段列出 |
| 排课助手推荐 | 跳过与不可用区间重叠的候选时段 |
| 未指定教师时 | 按班级默认教师判断占用与不可用，避免推荐出老师已经请假的时段 |

> 修正过程中发现一个旧问题：`conflictCheck` 在「同一时段没有任何已有排课」时会提前返回，导致教师不可用根本无法触发。已去掉该提前返回。

---

## 三、页面

课表页工具栏新增「排课配置」，一个弹窗两个页签：

- **停课日**：日期 + 名称，添加后立即出现在列表；周视图表头同步显示「停课」；
- **教师不可用**：选教师 + 起止时间（精确到分钟）+ 原因，列表可删除。

两个列表都支持直接删除，删除后周视图与推荐结果同步刷新。
