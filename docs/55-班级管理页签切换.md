# 班级管理：一对多 / 一对一页签切换

## 变更

班级管理顶部改为两个页签：

- 一对多班级（数量）
- 一对一班级（数量）

切换页签时：

- 表格数据只加载当前班型；
- 一对多表格显示「在学/容量」；
- 一对一表格显示「绑定学员」，不再显示容量列；
- 新增班级默认使用当前页签的班型；
- 新建/删除班级后同步刷新页签数量。

原来的「班型」筛选下拉移除，避免和页签重复。

## 验证

- 一对多页签表头：班级名称、课程、授课教师、教室、在学/容量、固定课表、状态、操作。
- 一对一页签表头：班级名称、课程、绑定学员、授课教师、教室、固定课表、状态、操作。
- 新建一对一班后切换到一对一页签，能看到班级和绑定学员。
- 前端生产构建通过。
