# 36 · 语义文字色治理

> UI/UX 审计的后续：主按钮对比度已修，但页面里仍散落着对比度不足的文字色。
> 这一轮把这些颜色收敛成语义 token，优先保证 12–14px 正文在白底上的可读性。

---

## 一、问题

| 颜色 | 常见用途 | 白底对比度 | WCAG AA |
|---|---|---|---|
| `#86909C` | 次要文字、时间、说明 | 3.24:1 | 失败 |
| `#D89614` | 待收款/待点名等警告数字 | 约 2.8:1 | 失败 |
| `#E5484D` | 缺勤、撤销、退费等危险文字 | 约 3.9:1 | 失败 |
| `#2BA471` | 成功/已收款文字 | 3.16:1 | 失败 |
| `var(--accent-6)` | 优惠、抹零、金额强调 | 2.94:1 | 失败 |

## 二、方案

在 `enterprise.less` 增加语义文字 token：

| Token | 值 | 白底对比度 |
|---|---|---|
| `--text-color-tertiary` | `#6B7280` | 4.83:1 |
| `--accent-text` | `#B84A0A` | 5.22:1 |
| `--warning-text` | `#9A6700` | 4.87:1 |
| `--danger-text` | `#CF1322` | 5.57:1 |
| `--success-text` | `#237A52` | 5.28:1 |

替换范围：

- 26 个视图/组件里的 `#86909C`、橙色/红色/绿色文字色；
- 全局 `enterprise.less` 中的列表说明、页头描述、指标标签、空态等；
- 工作台、H5 首页、收款台的指标数字通过辅助函数映射到语义色；
- 图表色板、图标背景、标签底色、渐变保留品牌色，不做替换。

## 三、验证

- 工作台指标标签/列表说明计算色为 `rgb(107,114,128)`，对比度 4.83:1。
- 学员卡片说明文字、页头描述、列表时间统一使用 `--text-color-tertiary`。
- 点名页缺勤/撤销、报名页优惠/抹零、工作台警告数字分别使用 danger/warning/accent 语义色。
- 前端 `npm run build` 通过。

## 四、边界

- 图表色板、状态标签的浅色背景、边框颜色仍是品牌色，未做对比度改造。
- 深色主题未重新验证。
- 真实用户可读性测试仍未进行。
- 仍有少量硬编码颜色（如标签背景 `#f6ffed`、图表色板），属于视觉资产而非正文文字。
