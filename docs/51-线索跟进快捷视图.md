# 线索跟进快捷视图

> 日期：2026-10-27

## 一、需求

招生线索页原来只有姓名/手机、状态、来源筛选；顾问要判断“今天该跟谁、谁已经逾期”只能自己看下次跟进时间。工作台带 `?todo=1` 进来时也只能看到混合的待跟进列表，无法区分今天和逾期。

验收标准：

- 线索页提供「全部 / 待跟进 / 今日跟进 / 已逾期」四个快捷视图；
- 今日跟进只包含下次跟进时间在今天的线索；
- 已逾期只包含下次跟进时间早于今天的线索；
- 待跟进包含今天及之前、且未报名/未流失的线索；
- 切换视图后列表立即刷新，顶部提示当前口径；
- 重置回到全部。

## 二、实现

后端 `CrmLeadPageParam` 增加 `nextFollowAfter`，与已有 `nextFollowBefore` 组合成时间区间；`CrmLeadServiceImpl` 增加 `nextFollowTime >= after` 条件。

前端 `/crm`：

- 新增快捷筛选按钮；
- `applyTodoFilter` 统一设置 `nextFollowAfter / nextFollowBefore / excludeStatus`；
- 工作台 `?todo=1` 自动选中「待跟进」；
- 提示条按当前视图显示不同口径。

## 三、验证

- 后端构建通过；前端构建通过（5419 个模块）；
- 本地接口：
  - 待跟进 2 条（赵小天、孙小美）；
  - 已逾期 2 条（赵小天、孙小美）；
  - 今日跟进 0 条；
- PC 页面实测四个快捷视图切换正常，逾期/今日/待跟进提示与列表一致；
- 无前端异常。

## 四、边界

- “今日/逾期”按浏览器本地日期计算，生产用户在东八区时与服务器日期一致；
- 线索跟进历史仍是最近 50 条，未加分页；
- 同手机号重复建线索的查重未在本次范围；
- 本次不发布生产。
