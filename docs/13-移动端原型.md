# 13 · 移动端 App 原型设计

> 目标：给教培机构做一支「老师/招生/前台/校长」都能用的手机 App。
> Android 壳只负责装一个 WebView，业务全部走 H5，因此**App 端与 PC 端不追求功能一致**：
> 手机上只保留**高频主流程**与**分视角报表**，复杂配置一律回 PC。

---

## 一、设计原则

| 原则 | 说明 |
|---|---|
| 手机只做"高频 + 现场" | 课表、点名、跟进、收款、看数。其余（课包配置、排课模板、权限）留在 PC |
| 一次一屏一件事 | 单页一个主任务，点名页只做点名，看板页只做看板 |
| 大按钮、少输入 | 主要操作放在底部或卡片右侧；能用选择就不用表单 |
| 弱网优先 | 列表先出骨架、请求失败给重试；关键操作可离线查看当天课表（缓存） |
| 壳极简 | Android 只做 WebView 容器 + token 注入 + 返回键/上传下载，业务逻辑全在 H5 |

## 二、角色视角矩阵

同一个账号进入 App 后可以切换「视角」，底部 Tab 随视角变化：

| 视角 | 适合谁 | 底部 Tab | 能做什么 |
|---|---|---|---|
| **教学**（老师/教务） | 授课老师、校区教务 | 课表 · 点名 · 学员 · 我的 | 今日课节、点名消课、我的课表、学员名册与课时余额 |
| **招生**（顾问/市场） | 招生顾问 | 线索 · 试听 · 学员 · 我的 | 我的线索、跟进记录、安排试听、转学员、我的转化 |
| **前台**（财务/前台） | 前台、财务 | 收款 · 退费 · 我的 | 待收款订单、扫码/手输收款、退费审批、收款流水 |
| **经营**（校长/机构管理员） | 校长、总部 | 看板 · 教学 · 招生 · 财务 · 我的 | 分视角报表：经营总览、教学质量、招生转化、财务收款 |

视角与角色码的映射（`superAdmin` 默认给全部视角）：

```js
const VIEW_BY_ROLE = {
  teacher: 'teach', teacherAdmin: 'teach',
  sales: 'enroll', salesAdmin: 'enroll',
  finance: 'cashier', cashier: 'cashier',
  superAdmin: 'all', bizAdmin: 'all'
}
```

## 四、关键页面原型

### 4.1 今日概览（首页）

```
┌─────────────────────────────┐
│ 星海艺术培训中心      [切换] │  ← 顶部栏：机构名 + 视角切换
│ 星期四 · 10月22日            │
├─────────────────────────────┤
│ ┌─────────┐┌─────────┐      │
│ │ 今日收款 ││ 今日课节 │      │  ← 2×2 指标块（按视角不同）
│ │ ¥3,600  ││   4 节  │      │
│ └─────────┘└─────────┘      │
│ ┌─────────┐┌─────────┐      │
│ │ 待收款  ││ 待跟进  │      │
│ │  3 笔   ││  5 条   │      │
│ └─────────┘└─────────┘      │
│                             │
│ 今日待办                      │
│ ┌─────────────────────────┐ │
│ │ 19:00 素描基础A1 · B201  │ │  ← 待办卡片，点即进入
│ │ 应到 12 人 · 待点名        │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 20:30 赵小雨 续费待跟进     │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│  课表    点名    学员    我的  │  ← 底部 Tab（按视角）
└─────────────────────────────┘
```

### 4.2 点名消课（现场高频）

- 顶部：班级名 + 时间 + 教室 + 应到人数
- 主体：学员列表，每行 `姓名 | 剩余课时 | [到课][请假][缺勤]`（大按钮，单选）
- 底部固定操作条：`全部到课` `提交点名`
- 提交后显示结果（成功消课 X 人 / 跳过 Y 人及原因），可返回课表

### 4.3 线索详情（招生跟进）

- 头部：学员姓名 + 家长手机（可点击拨号）+ 状态标签
- 时间线：历史跟进记录（电话/到访/试听）+ 下次跟进时间
- 底部固定：`写跟进` `安排试听` `转学员`

### 4.4 收款（前台）

- 订单摘要：学员 / 课包 / 应收金额 / 下单时间
- 收款方式：微信 / 现金 / 线下转账
- 确认收款 → 提示「已收款，课时已入账」

### 4.5 分视角报表（校长/管理员）

一个页面内用**顶部分段控件**切换四个视角，数据用现有报表接口：

| 视角 | 指标 | 接口 |
|---|---|---|
| 经营总览 | 收款/退费/净营收/课消课时/课消金额/新增学员/在读学员/续费预警 | `/finance/report/summary` |
| 教学质量 | 到课率/满班率排名/教师课时负荷/学员课时进度 | `/course/report/academic/*` |
| 招生转化 | 漏斗/来源/顾问跟进排行/试听转化 | `/crm/report/*` |
| 财务收款 | 收款趋势/渠道占比/校区排行/课包排行 | `/finance/report/trend|channel|campusRank|courseRank` |

## 五、主流程（时序）

```
老师          H5(App)              后端
 │  打开App ────▶ 加载 /app/home
 │               ├─▶ 今日课节(本周排课)
 │               ├─▶ 点名入口(未点名的课节置顶)
 │  点课节 ─────▶ /app/teach/attend
 │               ├─▶ 拉取名单 + 课时余额
 │  逐个点名 ───▶ 本地暂存(可返回)
 │  提交 ───────▶ /course/attend/confirm ──▶ 扣课 + 回补逻辑
 │               ◀── 成功/跳过原因
```

```
校长        H5(App)                  后端
 │ 打开App ──▶ /app/home(经营视角指标)
 │ 切报表 ───▶ /app/report ──▶ /finance/report/summary、/crm/report/funnel ...
 │ 切校区/时间 ─▶ 重新查询(移动端筛选条：时间 + 校区)
```

## 六、与 PC 的差异（明确不做）

| PC 有 | App 不做 | 原因 |
|---|---|---|
| 课包/课程/班级 CRUD、排课模板、批量生成 | 不做 | 低频，配置类操作回 PC |
| 权限管理、角色、数据范围、字典 | 不做 | 管理后台功能 |
| 课表导出、报表导出 | 只做"分享图片/转发" | 手机上导出文件不常用 |
| 多校区切换、复杂筛选 | 保留时间+校区两个筛选 | 手机屏幕放不下 |
| 全部 24 个事件码 | 只保留与主流程相关的埋点 | 移动端行为更集中 |

## 七、Android 壳（尽量简单）

只做 5 件事：

1. `WebView` 加载配置的 H5 地址（`BuildConfig.H5_BASE_URL`）
2. 启动时把 token 注入 H5（`localStorage`），实现免登录
3. 返回键：能后退就后退，不能后退就回首页，再不行退出
4. 文件选择/上传、下载（点名附件、报表图片）
5. 网络状态、版本检查

工程见 `app/`（Kotlin，单 Activity）。

## 八、当前实现（P0 已落地）

| 位置 | 内容 |
|---|---|
| `snowy-admin-web/src/views/app/**` | H5 原型（原型即实现）：外壳、登录、今日概览、课表、点名、学员名册、线索、线索详情、收款台、经营报表、我的 |
| `snowy-admin-web/src/store/app.js` | 移动端状态：视角（经营/教学/招生/前台财务）与用户信息 |
| `snowy-admin-web/src/router/systemRouter.js` | `/app/**` 静态路由（独立外壳，不走 PC 布局与动态菜单） |
| `snowy-admin-web/src/router/index.js` | `/app` 守卫：未登录去 `/app/login`；支持壳注入 `?token=` 免登录 |
| `app/` | Android 壳工程（Kotlin，单 Activity WebView） |
| `snowy-plugin-course/.../CourseClassStudent*` | 班级学员名单回填学员姓名（移动端点名、学员名册直接展示） |

已验证：手机视口（390×844）逐页走通，零控制台错误；PC 端全站巡检与接口冒烟不受影响。

### 角色体系已落地（见 docs/14-权限体系.md）

视角不再只是"演示用"：`principal / sales / teacher / cashier` 四个岗位角色已随租户开通自动创建，
角色码与视角一一对应；App 的「切换视角」按角色收敛，越权页面直接回首页。

### P0 阶段顺手修掉的问题

1. **未登录上报埋点会触发 401 弹窗**：页面访问埋点在无 token 时也上报，后端返回 401，前端弹出「登录已失效」并挡住登录页 → 改为无登录态不上报。
2. **移动端图标不显示**：AntD 的 `a-icon :component` 需要组件对象而非字符串名 → 改为 `<component :is>` + 显式引入图标组件。
3. **来源显示英文枚举**：线索来源 `GROUND` 等编码在前端裸奔 → 抽出 `utils/crmSource.js`，PC 与移动端共用同一份中文映射。
